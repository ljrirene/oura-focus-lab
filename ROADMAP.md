# Roadmap

## 0.1: Local-First Foundation

- [x] Oura API V2 OAuth and token refresh
- [x] Historical endpoint sync with raw snapshots
- [x] Incremental, failure-safe CSV updates
- [x] Local daily dashboard and trends
- [x] Profile-driven schedule, calendar export, and daily item check-off
- [x] Exploratory cognition and sleep-cycle reports
- [x] Privacy defaults and initial regression tests

## 0.2: Personalization

- [ ] Guided first-run setup for timezone, work hours, sleep target, and preferred exercise
- [x] Ignored local profile file with a checked-in neutral example
- [x] User-managed medication, supplement, and other daily items
- [ ] Optional interaction-spacing notes backed by authoritative references
- [ ] Configurable Readiness and workload rules
- [x] Optional AI-generated daily plan with validated sleep and medication boundaries
- [ ] Membership Hub export importer
- [ ] Demo mode with synthetic data and safe screenshots

## 0.3: Better Experiments

- [ ] Single-variable experiment builder and automatic baseline selection
- [ ] Missing-data and device-wear quality indicators
- [ ] Lagged associations for exercise, stress, meals, and sleep
- [ ] Confidence intervals and multiple-comparison warnings
- [ ] Optional one-tap subjective focus outcome
- [ ] Exportable experiment summaries without raw health data

## 0.4: Everyday App

- [x] Installable PWA shell with mobile home-screen support
- [ ] macOS packaging and launch-at-login option
- [x] Incremental scheduled sync with visible retry state
- [ ] Accessibility audit and English/Chinese localization
- [ ] Mobile layout and offline-state test coverage

## 1.0: Stable Local Health Workspace

- [ ] Encrypted local vault option
- [ ] Versioned storage schemas and migrations
- [ ] Pluggable analysis modules
- [ ] Reproducible, fixture-backed analytics validation
- [ ] Documented backup and restore workflow
- [ ] Stable privacy-preserving export format

Priorities are privacy, reliability, and interpretability before additional health recommendations.
